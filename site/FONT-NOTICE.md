# Font notice

Chinese headings use the system sans-serif stack (`SimHei`, `Microsoft YaHei`, `Heiti SC`, `PingFang SC`).
Chinese body text uses the system serif stack (`STZhongsong`, `华文中宋`, `SimSun`, `Songti SC`).
English text uses the self-hosted **MiSans** subset (Xiaomi, Apache License 2.0).
