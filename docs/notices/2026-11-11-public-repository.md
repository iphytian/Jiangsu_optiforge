`Jiangsu_optiforge` 公开信息仓库开始运行。仓库只发布以下公开信息：

- 公开通知
- 六个阶段门/里程碑的公开日期、状态和交付物类型
- 项目概览和公开活动信息

本仓库不发布个人联系方式、不宜公开的编号或其他不宜公开的内容。

欢迎通过 Issue 提交公开通知或更正建议。提交前请阅读 [公开发布规范](../../PUBLICATION-POLICY.md)。
